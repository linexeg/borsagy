BORSAGY.SI / BORSGAI.SI — FULL 3D WEBSITE DEPLOYMENT PACKAGE
منصة بورصجي (المرافق الذكي للمضاربين في البورصة المصرية EGX)

محتويات الحزمة (Package Contents):
1. index.html -> الموقع الكامل ثلاثي الأبعاد مع كافة تعديلات لوحة التحكم جاهز للرفع مباشرة.
2. assets/borsagy-si-logo-dark.svg -> الشعار الرسمي بصيغة Vector SVG للخلفيات الداكنة.
3. assets/borsagy-si-logo-light.svg -> الشعار الرسمي بصيغة Vector SVG للخلفيات الفاتحة والطباعة.
4. data/brokers_q3_2026.csv -> قالب بيانات شركات السمسرة (الربع الثالث 2026) مع حقول TO COLLECT.
5. data/borsagy-site-config.json -> ملف إعدادات ومحتوى لوحة التحكم الشاملة.

طريقة الرفع على نطاقك (How to upload to borsagy.si or borsgai.si):
- في لوحة استضافة موقعك (cPanel / Hostinger / Plesk):
  افتح File Manager ثم مجلد public_html وقم برفع وفك ضغط هذا الملف مباشرة.
- أو عبر Cloudflare Pages / Netlify / Vercel:
  قم بسحب وإفلات مجلد الحزمة لنشر الموقع فوراً مع شهادة SSL مجانية.
